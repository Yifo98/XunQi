# 讯栖发布记录

## 0.5.0 · 2026-07-17

- 首个正式版本；当前正式发布 macOS Apple Silicon 的源码 + 运行文件 ZIP，不使用 `.app`。
- 重新校准 Dock 图标视觉尺寸：保留暖白圆角底板与透明外边距，避免图标比相邻应用显得过大。
- 新增“全部 / 公众号 / 视频号”当前筛选一键全选，并明确区分“取消当前分类”与“取消全部已选”。
- 修复视频批量队列把已保存任务重复加入、终止状态未退出而长期显示“队列处理中”的问题。
- 视频队列跳过已保存或无需授权嗅探的项目；失败并恢复网络后会结束队列并显示可重试状态。
- 视频下载提供“原始画质”和“节省空间（微信默认）”两种真实策略；同一连续授权会话保持所选策略。
- 保留公众号批量原版 PDF、Markdown + 本地图片、视频进度与保存位置等既有能力。
- 仓库首页、双语演示、隐私边界、启动说明和正式发布包命名已统一为 `0.5.0`。
- Windows 正式包仍是独立发布门禁：待原生 Windows 真机验证后，再把源码 + BAT ZIP 追加到同一个 `v0.5.0` Release。

### 已知限制

- macOS 运行文件使用 ad-hoc 签名，未进行 Apple Developer ID 公证；首次启动可能需要在 Finder 中右键启动器并选择“打开”。
- 视频号授权嗅探会在用户确认后临时配置本地代理和会话证书；启用前需关闭 VPN，完成或失败后应确认网络已恢复。
- 当前视频队列采用单任务校验并自动续接，不同时运行多个授权嗅探任务，以避免串片、异步解密未完成或任务绑定错误。
- Windows 包尚未进入本次正式 Release；仓库中的 Windows 能力说明仅代表源码状态，不代表已完成真机发布验收。

## 0.5.0-beta.1 · 2026-07-15

- 首个公开预发布版本；Mac ZIP 包含源码、运行文件和平台启动器。
- macOS 包不再使用 `.app`，由 `Launch-XunQi.command` 启动 `runtime/xunqi`。
- Windows 旧版 `Launch-XunQi.cmd + runtime/XunQi.exe` 资产已于 2026-07-16 撤下，避免继续直接分发未知、未签名的 EXE。
- Windows 候选包改为完整源码 + `Launch-XunQi.bat`，不含 EXE、安装器或 runtime 目录；BAT 会在用户本机安装依赖并从源码编译。
- 修复 Windows 无法自动收取复制链接的问题：新增对 `WeChat.exe`、`Weixin.exe` 和 `WeChatAppEx.exe` 的原生前台识别。
- 仓库演示界面、测试数据与链接全部改为虚构内容，不收录真实公众号、视频号或用户任务。
- 当时的公开 GitHub Release 标记为 Pre-release；该版本现由正式版 `0.5.0` 接替。

### 继承自 0.4.9 的能力

- 兼容微信新版 `appmsg_type = 10002` 文字内容页，可读取标题、作者、发布时间和公开正文。
- 把完整微信链接粘贴到搜索框时，改为直接收取任务，不再将任务列表过滤为空。
- 支持多篇公众号文章批量导出原版 PDF。
- 支持视频号授权嗅探的连续会话、单任务校验队列、进度与保存位置展示。
- 支持按当前任务筛选结果一键全选；公众号/视频号切换后保留已有选择。
- 视频号提供“原始画质”与“节省空间（微信默认）”两种助手真实下载策略。连续授权期间不能中途切换，需先结束并恢复网络。
- 当前不同时运行多个授权嗅探任务：助手仍需逐条完成异步解密、文件容器校验和任务绑定，先以队列自动续接保证不会串片或导出未完成文件。
- 公众号公开文章读取、单篇与批量 PDF、Markdown 和本地图片导出。
- 视频号公开直链下载，以及 macOS 用户明确授权后的本地嗅探辅助流程。

### 已知限制

- macOS 运行文件使用 ad-hoc 签名，未进行 Apple Developer ID 公证。
- Windows 源码包不分发预编译 EXE，但本地开发构建仍未签名，也可能被 SmartScreen、Smart App Control 或企业 App Control 策略拦截；BAT 不是绕过方案。
- Windows 不包含 macOS 专用的视频号授权嗅探助手。
- 预发布包用于调试与验收，不承诺稳定版兼容性。
