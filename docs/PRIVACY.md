# 讯栖隐私边界

讯栖是本地优先工具。文章快照、任务状态、导出文件和下载文件保存在用户自己的电脑上，项目不提供云端账号、远程数据库或遥测上报。

## 默认模式

- 只处理用户复制的微信公开分享链接。
- 不读取微信聊天记录、通讯录、本地数据库或密码。
- 公众号公开文章读取不使用微信 Cookie 或登录态。
- 不会自动导出、自动完整备份或下载未勾选内容。

## 授权嗅探模式

只有视频号公开页面没有提供直接媒体地址、且用户明确点击授权时，讯栖才会在 macOS 或 Windows 试验适配上启动本地助手。Windows 不使用指纹授权，且只操作当前用户的代理和证书库。

- 启用期间系统 HTTP/HTTPS 请求会先经过本地助手。
- 匹配页面的 Cookie 与会话数据只在本机内存中临时经过，不在讯栖 UI 显示，不写入日志，不上传。
- Windows 第三方助手的 `app.log` 仅存于当次会话的私有临时目录，不进入讯栖诊断导出，且在会话结束或恢复时随临时目录删除。
- 用户点击“结束并恢复网络”或退出讯栖后，应恢复原网络设置并移除会话证书。
- 授权期间请暂停网银、密码修改等敏感操作。

## 本地数据与删除

- 移除任务会清理讯栖内部的正文、视频识别结果和相关临时文件记录。
- 已导出到用户所选文件夹的 PDF、Markdown、图片和视频不会被自动删除。

## 诊断日志

- 讯栖在本机保存受控的功能事件码和成功/失败分类，用于排查启动、读取、导出与下载问题。
- 顶部“导出日志”（“关于”页同样可用）只导出时间、版本、系统类型、事件码和错误类别。
- 诊断日志不记录 Cookie、聊天记录、文章正文、分享链接、密码、令牌或用户输入内容。
- 日志不会自动上传；只有用户主动导出并自行发送时才会离开本机。
