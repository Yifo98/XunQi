# 讯栖 0.5.0 正式版

讯来有迹，文止于栖。

这是讯栖的首个正式版本。当前 Release 先提供已经完成本地验证的 macOS Apple Silicon 压缩包；Windows 已改为由原生 Windows Runner 生成的免开发环境便携候选包，完成真机验收后再追加到同一个 `v0.5.0` Release。

## 主要能力

- 自动收取用户在微信前台主动复制的公众号文章与视频号分享链接，也支持直接粘贴链接。
- 工作台界面支持中文 / English 一键切换，原始文章和视频内容保持原文。
- 公众号文章可单篇或批量导出原版 PDF，也可导出 Markdown + 本地图片。
- 任务可按全部、公众号、视频号筛选并一键全选；切换分类后仍保留选择，并可明确取消当前分类或全部已选。
- 视频号支持公开直链下载，以及 macOS 用户明确授权后的本地嗅探辅助流程；Windows 适配尚属试验功能。
- 视频下载提供“原始画质”和“节省空间（微信默认）”两种真实策略。
- 多条视频按单任务校验队列自动续接；已保存内容会跳过，失败或恢复网络后不会永久停留在“队列处理中”。
- 显示下载进度、速度、文件大小、完成后分辨率和保存位置。
- 删除任务时清理讯栖内部正文、资源和识别缓存，不删除用户已经导出的文件。

## macOS 下载与启动

下载：

- `XunQi-0.5.0-macOS-arm64-source.zip`
- `XunQi-0.5.0-macOS-arm64-source.zip.sha256`

完整解压后，双击外层的 `Launch-XunQi.command`。压缩包不使用 `.app`，包含运行文件、对应源码、启动器和必要的第三方许可说明。

当前运行文件使用 ad-hoc 签名，未进行 Apple Developer ID 公证。若 macOS 首次阻止启动器，请确认文件来自本仓库 Release 并核对 SHA-256，然后在 Finder 中右键 `Launch-XunQi.command`，选择“打开”。

## 安全与隐私边界

- 讯栖不读取微信聊天记录、通讯录、本地数据库或密码。
- 默认公众号公开页面读取不使用微信 Cookie。
- 本地任务、正文、缓存与导出内容不上传到讯栖服务器；项目不提供云端账号、远程数据库或遥测服务。
- 视频号授权嗅探只在用户确认后临时启用本地代理和会话证书。启用前请关闭 VPN；使用完毕后点击“结束并恢复网络”。
- 讯栖不提供录屏保存，不绕过 DRM 或内容访问权限。请只保存你有权访问和使用的内容。

## 平台说明

- macOS Apple Silicon：本次正式发布并完成本地构建、启动、导出与队列回归验证。
- Windows x64：便携候选包已通过原生 Windows Runner 测试、编译、BAT 与 ZIP 白名单校验，包含未商业签名的运行文件；授权嗅探使用当前用户证书库，不使用指纹或 Windows Hello 授权。根据系统或企业策略，首次可能出现证书信任确认。完成 Windows 真机验收后再追加公开 Release。
