# 讯栖 0.5.1 正式版

讯来有迹，文止于栖。

`0.5.1` 将本地已经验证的最新 macOS 功能、工作台布局与双语界面同步到 GitHub。旧版 `v0.5.0` 保持不变，便于校验与回退。

## 本次更新

- 中文 / English 一键切换，并记住上次选择的语言。
- 重新整理顶部品牌、帮助、日志与监听状态区域，减少按钮和提示文字换行拥挤。
- 顶部和“关于”页都可以导出诊断日志。
- 诊断文件只包含时间、版本、平台、受控事件与结果分类，不包含 Cookie、聊天记录、文章正文、分享链接、密码或令牌。
- 继续支持按全部、公众号、视频号筛选后全选；可取消当前分类或一次取消全部已选。
- 继续支持多篇公众号文章批量导出原版 PDF、单篇 Markdown 与本地图片。
- 继续支持 macOS 视频号公开直链下载和用户明确授权后的本地嗅探辅助流程。

## 下载与启动

- `XunQi-0.5.1-macOS-arm64-source.zip`
- `XunQi-0.5.1-macOS-arm64-source.zip.sha256`

完整解压后双击 `Launch-XunQi.command`。压缩包不使用 `.app`，外层只保留启动器、说明、运行文件目录和同提交源码。

运行文件使用 ad-hoc 签名，尚未进行 Apple Developer ID 公证。若 macOS 首次阻止启动，请先确认下载来源并核对 SHA-256，然后在 Finder 中右键启动器并选择“打开”。

## 平台说明

- macOS Apple Silicon：本次正式发布，完成构建、测试、启动器、压缩包结构和校验值验证。
- Windows：暂停发布。公开源码中的试验适配继续保留供后续研究，本次 Release 不提供 Windows ZIP 或运行文件。

## 隐私边界

- 只处理用户主动复制或粘贴的微信分享链接。
- 公众号公开文章读取默认不使用微信 Cookie 或登录态。
- 不读取微信聊天记录、通讯录、本地数据库或密码。
- 本地任务、缓存、诊断和导出结果不上传到讯栖服务器。
- 不承诺或尝试匿名枚举任意公众号的全部历史文章。
