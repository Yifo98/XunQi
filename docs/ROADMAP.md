## 下一项：自有公众号评论同步

官方资料调研已完成，详见 [微信公众号文章评论获取研究](COMMENT-RESEARCH.md)。结论是：已认证且具备留言权限的自有公众号，可通过微信官方服务端 API 同步评论；任意第三方公众号的公开文章，没有仅凭分享 URL 即可匿名读取评论的官方接口。

实现顺序：

1. 建立只保管密钥和微信令牌的服务端连接器，桌面端不保存 `AppSecret`。
2. 用一个真实、已认证且具备留言权限的自有账号，跑通 `msg_data_id + index` 与文章的映射。
3. 首版默认只同步精选评论，丢弃 `openid`，只读不提供删除、回复等写操作。
4. PDF / Markdown 导出增加“附带精选评论”可选项，并让评论缓存跟随文章任务删除。
5. 未经公众号管理员授权的文章只显示限制说明，不尝试读取 Cookie 或未公开接口。
