讯栖 · macOS 0.5.0 正式版

使用方法
1. 解压整个 ZIP 压缩包，不要在压缩包内直接运行。
2. 双击“Launch-XunQi.command”打开。压缩包不包含 .app，实际运行文件位于 runtime 文件夹。
3. 保持讯栖运行，在微信内打开公众号文章或视频号内容。
4. 公众号文章：点击右上角的三个点（部分微信版本显示四个点），选择“复制链接”。
5. 视频号：点击分享箭头，在弹出的菜单中选择“复制链接”。
6. 讯栖会自动识别链接类型和来源。预览读取结果后，再手动选择导出原版 PDF、导出 Markdown、下载公开视频或授权嗅探下载。
7. 公众号默认生成保留标题、段落、引用、列表和原文图片位置的离线长页 PDF；也可以切换为 Markdown + 本地图片。
8. 如果自动监听没有立即收取，可把完整微信分享链接直接粘贴到左侧搜索框；讯栖会自动清空搜索框并将链接收取为任务。

多任务处理
- 左侧可按标题、作者或来源搜索，并在全部、公众号、视频号之间筛选。
- 任务按来源分组；可折叠、展开、多选，也可一键全选当前筛选结果。切换公众号/视频号分类不会丢失已经勾选的任务。
- 勾选多篇公众号文章后，右侧会出现“批量处理并导出 PDF”；只需选择一次本地文件夹。
- 勾选多条零直链视频后，右侧会出现“开始连续下载”；只需首次授权和选择一次保存目录，随后按单任务校验队列逐条自动接续。
- 未读取的公众号文章会先处理再导出；视频号队列和公众号 PDF 队列彼此独立。
- “移除并清缓存”会删除讯栖内部正文和识别缓存，但不会删除已导出的本地文件。
- 保存完成后可点击“在 Finder 中显示”定位输出文件夹。

安全边界
- 讯栖不通过公众号名称连接微信服务器。
- 默认公开识别不读取 Cookie、聊天记录或微信本地数据库。
- 默认识别不安装证书、不修改系统代理、不抓包，也不绕过登录、加密或 DRM。
- 视频号分享页没有公开 HTTPS 视频文件时，讯栖会显示微信公开页面返回的准确限制，不会把封面误判为视频。
- 零直链视频可选择“授权嗅探下载”。只有你确认后，讯栖才临时把系统 HTTP/HTTPS 流量接入本地助手并安装会话证书。首条完成后会保留授权；单条失败也不会立刻销毁授权。已明确勾选的队列会继续下一条，不再重复确认。Windows 不使用指纹授权；macOS 可能仅在首次要求 Touch ID 或管理员确认。
- 首次授权后，讯栖会重新加载一次视频号子窗口，但不会退出微信聊天主程序。请从微信左侧重新进入一次“视频号”；后续下载不会再重载。讯栖始终按已复制的分享链接下载原来那条，不会把推荐页上的其他视频当成目标。
- 授权前可选择“原始画质（文件较大）”或“节省空间（微信默认）”。连续授权期间需保持同一画质；如要切换，请先“结束并恢复网络”再重新启用。
- 讯栖会显示下载百分比、大小、速度、实际使用的画质、完成后的分辨率和保存目录。你可随时点击“打开保存位置”或“结束并恢复网络”。
- 启用嗅探前必须关闭 VPN 和系统代理。检测到已启用代理时，讯栖会阻止启动而不是覆盖原设置。点击“结束并恢复网络”或退出讯栖时，会恢复原网络设置并移除会话证书。
- 授权期间系统 HTTP/HTTPS 请求会先经过本地助手。助手只对预设的微信/腾讯页面进行解析，其他流量只转发、不保存。匹配页面的 Cookie 与登录态仅在本机内存中临时经过助手，不显示、不写日志、不落盘、不上传。
- 因为会临时信任本地证书，这不是零风险功能。启用期间请暂停网银、密码修改等敏感操作，使用完后主动点击“结束并恢复网络”。
- 视频号环境连上后，讯栖会自动提交当前任务里已经复制的分享链接，并只绑定该链接返回的下载任务。即使推荐页显示了另一条，也不会把它当成当前任务。若长时间没有开始，请从微信左侧退出“视频号”后再进入一次；仍无反应时点击“停止并恢复网络”。
- 本地助手或链接提交短暂失败时会先自动重试；单条失败时只清理该条临时文件并保留连续授权。连续失联、超时或安全校验失败时才会停止会话并恢复网络。
- 讯栖不提供屏幕录制或录制视频文件的功能。
- 不会下载未勾选的视频，不建立完整备份。只有用户明确启动的队列会按单任务校验自动接续；当前版本不同时运行多条授权嗅探任务。

数据说明
- V2 使用独立的本地数据文件，不会显示旧版来源、收件箱和历史记录。
- 导出文件保存在你选择的目录；讯栖不会上传这些内容。

源码说明
- source 文件夹是与本正式包同一提交的完整源码，不含 .git、node_modules、构建缓存和用户数据。
- runtime 文件夹只放运行所需文件。不要单独移动其中的文件，否则 PDF 和授权嗅探助手可能失效。
- 当前压缩包未进行 Apple Developer ID 公证。若 macOS 首次阻止启动器，可在 Finder 中右键“Launch-XunQi.command”并选择“打开”。
