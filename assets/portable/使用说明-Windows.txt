讯栖 · Windows x64 源码预发布版

使用方法
1. 完整解压 ZIP，不要在压缩包内直接运行。
2. 双击“Launch-XunQi.cmd”。
3. 在微信中复制公众号文章或视频号分享链接。
4. 微信位于前台时，讯栖会监听随后复制的新分享链接；也可以把完整链接粘贴到讯栖左侧搜索框。

Preview 已支持
- 公众号公开文章读取。
- Markdown + 本地图片导出。
- 已安装 Microsoft Edge 时导出原版 PDF。
- 页面公开 HTTPS 直链视频的手动下载。

Preview 暂未对齐 macOS
- 不包含 macOS 专用的视频号授权嗅探助手。
- 未进行 Windows 代码签名，SmartScreen 可能显示来源提示。

源码说明
- source 文件夹是与本预发布包同一提交的完整源码，不含 .git、node_modules、构建缓存和用户数据。
- runtime 文件夹中的 XunQi.exe 是 Windows 实际运行必需的程序格式；外层压缩包仍是免安装源码包。

隐私与安全
- 默认公开文章读取不使用微信 Cookie。
- 任务、正文与导出内容保存在本机，讯栖不提供云端账号或遥测上报。
