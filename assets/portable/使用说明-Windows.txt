讯栖 · Windows 源码 + BAT 预发布版

使用方法
1. 完整解压 ZIP，不要在压缩包内直接运行。
2. 安装 Node.js 22、pnpm 11、Rust stable、Windows MSVC 构建工具和 WebView2。
3. 双击“Launch-XunQi.bat”。首次运行会联网安装依赖，并从源码编译讯栖。
4. 在微信中复制公众号文章或视频号分享链接。
5. 微信位于前台时，讯栖会监听随后复制的新分享链接；也可以把完整链接粘贴到讯栖左侧搜索框。

包内容
- 外层只保留 Launch-XunQi.bat、本文档和完整 source 目录。
- 不包含 XunQi.exe、MSI、MSIX、APPX、CMD 启动器或 runtime 目录。
- source 不含 .git、node_modules、构建缓存和用户数据。

智能应用控制说明
- 当前预览版没有 Windows 商业代码签名。签名用于让 Windows 验证发布者身份和文件是否被篡改，不是讯栖的功能依赖，也不会赋予软件额外的系统权限；在 Windows 没有拦截的环境中，未签名不影响功能本身。
- BAT 本身不等于受信任应用，也不能绕过 Windows Smart App Control。
- BAT 启动的 Node.js、pnpm、Rust 工具和本地编译出的讯栖程序仍可能被 Windows 检查。
- “未签名”不等于恶意软件，但新项目缺少下载声誉时更容易触发 Windows 提醒或拦截。

如果 Windows 提醒或拦截
1. 先确认 ZIP 来自 https://github.com/Yifo98/XunQi/releases，并核对同名 .sha256 文件；再使用 Microsoft Defender 扫描。
2. 如果文件属性只提示“此文件来自其他计算机，可能被阻止”，可右键 ZIP → 属性 → 常规 → 解除锁定 → 应用，然后重新完整解压。这只移除下载来源标记，不会关闭 Defender 或智能应用控制。
3. 如果明确显示“智能应用控制已阻止此应用”，Windows 目前没有针对单个应用的放行按钮。优先在 Windows Sandbox、虚拟机或专门的开发环境中验证，或等待正式签名版本。
4. 如果你理解风险并决定临时关闭：打开 Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置 → 关闭；完成后及时重新开启。此操作会降低系统保护，讯栖不会自动替你修改。
5. 公司或学校电脑若由 App Control 管理，请联系管理员加入允许列表；不要自行削弱组织策略。
6. 如果 Defender 明确报告木马、恶意软件或潜在有害程序，请停止运行，不要强行放行，并向项目 Issue 提交脱敏截图和校验值。

Preview 已支持
- 公众号公开文章读取。
- Markdown + 本地图片导出。
- 已安装 Microsoft Edge 时导出原版 PDF。
- 页面公开 HTTPS 直链视频的手动下载。

Preview 暂未对齐 macOS
- 不包含 macOS 专用的视频号授权嗅探助手。
- 本地开发构建未进行 Windows 代码签名，仍可能被 SmartScreen、Smart App Control 或企业 App Control 策略拦截。

隐私与安全
- 源码公开可审阅；Windows 包不携带预编译讯栖 EXE、安装器或后台服务。
- 只在微信位于前台时识别随后复制的新分享链接；不持续扫描全部剪贴板历史。
- 不读取微信聊天记录、通讯录、本地数据库或密码。
- 默认公开文章读取不使用微信 Cookie。
- 任务、正文与导出内容保存在本机，讯栖不提供云端账号、远程数据库或遥测上报。
- 首次安装依赖、读取公开页面和下载用户选择的内容需要联网；讯栖不会把本地任务或导出内容上传到自有服务器。
