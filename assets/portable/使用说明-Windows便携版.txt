讯栖 · Windows x64 免开发环境便携包

普通用户使用方法
1. 完整解压 ZIP，不要在压缩包内直接运行。
2. 双击 Launch-XunQi.bat。
3. 不需要安装 Node.js、pnpm、Rust 或 MSVC 构建工具。
4. 在微信中复制公众号文章或视频号分享链接，讯栖会在微信位于前台时收取随后复制的新链接。

诊断日志
- 讯栖能打开：点击顶部“导出日志”（“关于”页也有同一入口），选择保存位置；导出后会自动在资源管理器中显示 TXT 文件。
- 讯栖打不开：双击 Open-XunQi-Logs.bat，打开 launcher.log 所在文件夹。
- 诊断日志只记录时间、版本、系统类型、受控功能事件以及成功/失败分类。
- 日志不记录 Cookie、微信聊天记录、文章正文、分享链接、密码或令牌。

包内容
- Launch-XunQi.bat：普通用户启动器。
- Open-XunQi-Logs.bat：仅打开本机启动日志文件夹。
- README-Windows.txt：本文档。
- runtime/xunqi.exe：由 GitHub 的原生 Windows Runner 从公开源码构建的运行文件。
- 不包含源码开发依赖、安装器、后台服务、Node.js、pnpm、Rust 或 MSVC。

Windows 安全提示
- 当前测试包没有商业代码签名。签名用于验证发布者身份与文件完整性，不是功能依赖；未签名本身不会赋予讯栖额外权限，也不等于恶意软件。
- SmartScreen、Smart App Control 或企业 App Control 仍可能检查 BAT 和 xunqi.exe。BAT 不是安全功能绕过方案。
- 先确认 ZIP 来自 https://github.com/Yifo98/XunQi/releases，并核对同名 .sha256，再用 Microsoft Defender 扫描。
- 如果只是“来自其他计算机”的下载标记，可右键 ZIP → 属性 → 解除锁定，再重新完整解压。
- 如果 Defender 明确报告恶意软件，请停止运行并提交脱敏截图与校验值，不要强行放行。
- 如果智能应用控制明确阻止且没有单应用放行入口，请优先使用 Windows Sandbox/虚拟机测试，或等待正式签名版本；讯栖不会自动关闭系统保护。

隐私边界
- 只在微信位于前台时识别随后复制的新分享链接，不扫描全部剪贴板历史。
- 不读取聊天记录、通讯录、微信本地数据库或密码。
- 默认读取公开文章时不使用微信 Cookie。
- 任务、正文、导出结果和诊断日志保存在本机，不提供云端账号、遥测或远程日志上传。

当前 Windows 差异
- 支持公众号公开文章读取、Markdown + 本地图片和使用 Microsoft Edge 导出 PDF。
- 支持页面公开 HTTPS 视频直链的手动下载。
- 不包含 macOS 专用的视频号授权嗅探助手。
