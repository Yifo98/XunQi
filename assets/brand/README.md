# 讯栖品牌方向

- 品牌名称：**讯栖**
- 图标基础：F「小巡」的蓝紫轨道与暖黄色新内容方块
- 产品隐喻：信号在本地安静归巢，由用户决定是否查看与备份

## 必须保留

- 蓝紫柔和渐变、圆角、轻量立体感
- 环形巡视后返回的动作
- 单个暖黄色内容方块作为视觉焦点
- 无脸、无具体人物，但保留轻陪伴感
- 小尺寸和菜单栏状态下仍可识别

## 必须避免

- 蜘蛛、爬虫、下载、盾牌、锁或安全软件视觉
- 平台官方标志和仿官方联名
- 儿童化吉祥物、监控摄像头、雷达准星
- 把图标做成 Wi-Fi、投屏或网络加速器

当前 PNG 是已确认的方向稿，不是最终生产矢量文件；正式发布前仍需小尺寸重绘、矢量化和商标近似检索。
