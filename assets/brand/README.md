# 讯栖 XunQi · 栖｜QIDU 品牌方向

- 品牌名称：**讯栖 XunQi · 栖**
- 母品牌：**器度 QIDU**
- 统一署名：**A QIDU Utility**
- 品牌题记：**讯来有迹，文止于栖。**
- 图标基础：蓝紫归栖轨道、接收箭头与暖黄色内容方块
- 产品隐喻：信息被用户主动接住，在本地巡视、整理并归栖

## 生产文件

- `xunqi-qidu-master.png`：1254×1254 品牌母版，来自小夫确认的方向板与本轮生产草案。
- `xunqi-ui.png`：256×256 界面用图标。
- `xunqi-dock.png`：512×512 Dock 图标，保留圆角暖白底板与约 9% 的透明安全边距。供不使用 `.app` 的 macOS 裸二进制设置图标，既不显示方形白边、不让字标直接浮在桌面上，也避免在 Dock 中比相邻应用显得过大。
- `xunqi-icon-direction.png`：上一版方向记录，仅供历史对照，不再用于应用界面。
- `src-tauri/icons/`：由 `xunqi-dock.png` 统一生成 Tauri 当前配置使用的 macOS、Windows 与小尺寸图标。

## 必须保留

- 蓝紫柔和渐变、圆角、轻量立体感
- 环形巡视后返回、接住内容的动作
- 单个暖黄色内容方块作为视觉焦点
- 无脸、无具体人物，但保留轻陪伴感
- 小尺寸和菜单栏状态下仍可识别

## 必须避免

- 蜘蛛、爬虫、下载、盾牌、锁或安全软件视觉
- 平台官方标志和仿官方联名
- 儿童化吉祥物、监控摄像头、雷达准星
- 把图标做成 Wi-Fi、投屏或网络加速器

当前生产母版为高分辨率 PNG，并已完成小尺寸派生；正式公开前仍需进行商标近似检索。若后续需要印刷或无限缩放，再基于同一轮廓补充人工校正的 SVG，不应重新改变图形概念。
